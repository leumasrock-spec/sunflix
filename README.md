# 🌻 Sunflix

Vídeos de estudo do Prof. Samuel Rocha (Biologia, Ciências, Química 9º ano e Direito/Fiscalização Ambiental), organizados por categoria a partir das playlists do canal **@leumasrock** no YouTube. Inspirado no material **Bioflix**.

Site: https://leumasrock-spec.github.io/sunflix/

- `index.html` – site completo (dados embutidos)
- `data/sunflix.json` – lista de categorias, vídeos e links de apoio
